# 어떤 애플워치에서 되나

설치 전에 본인 워치가 어디에 해당하는지 확인하세요.
`설정 → 일반 → 정보` 에서 모델명과 watchOS 버전을 볼 수 있습니다.

---

## 1. 앱이 설치되는가 — watchOS 10 이상

이 앱은 **watchOS 10.0 이상**이 필요합니다.

| watchOS | 설치 가능한 모델 |
|---|---|
| **10** | Series 4 · 5 · 6 · 7 · 8 · 9 · SE(1세대) · SE(2세대) · Ultra · Ultra 2 |
| **11** | Series 6 · 7 · 8 · 9 · 10 · SE(2세대) · Ultra · Ultra 2 |

> watchOS 11 에서 **Series 4 · 5 · SE 1세대가 빠졌습니다.**
> 이 기기들은 watchOS 10 이 마지막이라, 10 을 쓰는 동안은 이 앱이 돕니다.

**Series 3 이하는 안 됩니다.** watchOS 10 을 못 올립니다.

---

## 2. 검지·엄지 두드림(더블 탭)이 되는가

승인을 손목 동작만으로 처리하는 기능입니다. **기기와 OS 둘 다 조건이 있습니다.**

| | 조건 |
|---|---|
| **기기** | Series 9 · Series 10 · Ultra 2 **이상** |
| **OS** | 시스템 더블 탭은 watchOS 10.1+, 앱이 쓰려면 **watchOS 11+** |

### 안 되는 모델

```
Series 8 이하 · SE 전 세대 · Ultra(1세대)
```

**안 돼도 앱은 정상 동작합니다.** 화면의 승인 버튼을 손가락으로 누르면 됩니다.
더블 탭은 "화면을 안 보고도 승인"하는 편의 기능일 뿐입니다.

> Ultra 1세대는 헷갈리기 쉽습니다. **Ultra 2 부터** 됩니다.

---

## 3. Wi-Fi 로 붙으면 어디까지 되나

워치가 인터넷에 붙는 방법은 셋이고, **위에서부터 되는 걸 씁니다.**

```
① 아이폰 (블루투스)   가까이 있을 때. 배터리를 제일 아낍니다
② Wi-Fi              아이폰이 멀고 아는 Wi-Fi 가 있을 때
③ LTE                위 둘이 다 없을 때 (셀룰러 모델만)
```

### 기능은 어느 경로로 붙든 똑같습니다

| 기능 | 아이폰 경유 | Wi-Fi | LTE |
|---|---|---|---|
| 세션 목록·대화 보기 | ✅ | ✅ | ✅ |
| 승인 / 거부 | ✅ | ✅ | ✅ |
| 음성 지시 | ✅ | ✅ | ✅ |
| 승인 푸시 알림 | ✅ | ✅ | ✅ |

브리지에는 공개 주소(`.ts.net`)로 붙기 때문에, **경로가 무엇이든 인터넷만 되면 전부 동작합니다.**

### 그래서 실제로 갈리는 건 "어디까지 나갈 수 있나"

애플워치는 두 종류로 팔립니다. 상자와 `설정 → 일반 → 정보` 의 **모델명**에 적혀 있습니다.

| 모델명 표기 | 흔히 부르는 이름 | 통신 |
|---|---|---|
| `GPS` | **Wi-Fi 전용 모델** | Wi-Fi · 블루투스 |
| `GPS + Cellular` | 셀룰러 모델 | Wi-Fi · 블루투스 · **LTE** |

| | 집·사무실 (Wi-Fi 안) | 아이폰과 함께 외출 | **아이폰 없이 외출** |
|---|---|---|---|
| **Wi-Fi 전용 모델** | ✅ 전부 됨 | ✅ 아이폰 경유로 됨 | ❌ **아무것도 안 됨** |
| **셀룰러 모델** | ✅ 전부 됨 | ✅ 됨 | ✅ **LTE 로 전부 됨** |

**Wi-Fi 전용 모델도 이 앱을 쓸 수 있습니다.** 기능에 제한이 없습니다 —
집이나 사무실 Wi-Fi 안에 있거나, 아이폰이 주머니에 있으면 승인·지시·대화 전부 됩니다.

다만 **아이폰을 두고 나가면 그때부터 아무것도 못 합니다.** 워치가 인터넷에 나갈 길이
없기 때문입니다. 산책·운동처럼 워치만 차고 나가는 상황에서 쓰시려면 셀룰러 모델이어야 합니다.

> **셀룰러 모델이라도 통신사 요금제에 워치를 등록해야 LTE 가 켜집니다.**
> 등록하지 않으면 사실상 Wi-Fi 전용 모델과 같습니다.

## 4. 설치할 때만 필요한 조건

평소 사용과 별개로, **앱을 처음 넣을 때는** 워치가 맥과 **같은 Wi-Fi** 에 있어야 합니다.

워치는 아이폰이 가까이 있으면 블루투스를 쓰고 Wi-Fi 에 안 붙습니다.
그래서 설치 직전에 **아이폰 블루투스를 잠깐 꺼서** 워치가 스스로 Wi-Fi 에 붙게 해야 합니다.
설치가 끝나면 다시 켜셔도 됩니다.

---

## 5. 맥 쪽 조건

| | |
|---|---|
| macOS | Xcode 가 도는 버전 |
| Xcode | watchOS SDK 포함 |
| Node | 20 이상 |
| 애플 개발자 계정 | 유료면 1년, **무료면 7일마다 재설치** |

무료 계정으로도 쓸 수 있지만, 7일마다 다시 빌드해서 넣어야 합니다.

## 요약 — 가장 좋은 조합

```
Apple Watch Series 9 이상 (셀룰러)  ·  watchOS 11 이상
→ 더블 탭 승인 + 아이폰 없이 LTE 로 어디서나
```

```
Series 4~8 · SE · Ultra 1세대
→ 앱은 정상 동작. 더블 탭만 안 됨 (화면 탭으로 승인)
```

```
Wi-Fi 전용 모델 (모델명에 GPS 만 있음)
→ 기능은 전부 동작. 단, 아이폰을 두고 나가면 못 씀
```
