# 클로드워치 (ClaudeWatch) 개발 기획안

애플워치(LTE)로 맥에서 실행 중인 클로드코드를 원격 조종하는 시스템.
아이폰/맥 근처가 아니어도 LTE만으로 세션 확인, 승인/거부, 음성 지시, 새 세션 생성이 가능해야 한다.

---

## 1. 목표

- 워치 단독(LTE)으로 클로드코드 원격 제어
- 승인 요청이 오면 손목 진동 알림 → 알림 또는 목록에서 즉시 승인/거부
- 세션 결과를 워치 화면에 맞게 짧게 요약해서 확인
- 워치 마이크(받아쓰기)로 세션에 지시 전송
- 워치에서 새 세션 생성 시, 클로드 공식 앱(핸드폰)과 데스크톱 터미널에서도 같은 세션이 보이도록 동기화

## 2. 전체 아키텍처

```
⌚ watchOS 앱 (LTE)
   │  HTTPS (Tailscale 사설망 주소)
   ▼
🖥️ 맥 브리지 서버 (Node.js)
   │  자식 프로세스로 클로드코드 세션 실행/관리
   ▼
클로드코드 세션들
   │  Anthropic 서버에 자동 등록 (remote-control 드라이버일 때)
   ▼
📱 클로드 공식 앱 · 🖥️ 데스크톱 터미널 → 같은 세션 자동 표시
```

핵심 원리:
- 워치 ↔ 맥 통신은 Tailscale 사설망을 통해 직접 연결 (공유기 포트포워딩 불필요).
- 승인 요청 알림은 APNs 푸시로 즉시 전달.

## 3. 구성 요소

### 3-1. 맥 브리지 서버
- 역할: 세션 생성/종료/목록 관리, 클로드코드 출력 파싱, 승인 요청 감지, 결과 요약, APNs 푸시 발송
- 승인 프롬프트 감지 시:
  1. 세션 상태를 `waiting_approval`로 변경
  2. 실행하려는 명령어를 추출
  3. APNs로 워치에 푸시 발송 (카테고리: 승인/거부 액션 버튼 포함)
- 결과 요약: 세션 출력이 길 경우 워치용 3~4줄 요약 생성

### 3-2. REST API (브리지 서버 ↔ 워치)

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | /sessions | 세션 목록 + 상태(running / waiting_approval / done) |
| POST | /sessions | 새 세션 생성 `{ project, firstPrompt }` |
| GET | /sessions/:id | 세션 상세 (요약 결과, 대기 중 명령어) |
| GET | /sessions/:id/log | 전체 로그 |
| POST | /sessions/:id/approve | 승인 |
| POST | /sessions/:id/deny | 거부 |
| POST | /sessions/:id/prompt | 텍스트 지시 전송 `{ text }` |
| GET | /projects | 세션 생성 시 선택할 프로젝트 목록 |

- 인증: 토큰 헤더 (Tailscale 사설망 내부라 이중 안전장치 수준)

### 3-3. watchOS 앱 (SwiftUI)
- watchOS 10+, LTE 단독 통신 필수 (iPhone 없이 동작)
- 음성 입력: watchOS 내장 받아쓰기(dictation) → 텍스트 변환 후 API 전송
- 푸시: APNs 알림 카테고리에 "승인"/"거부" 액션 버튼 → 앱 안 열고 알림에서 바로 처리

## 4. 화면 명세 (5개 화면)

### ① 세션 목록 (메인)
- 세션 카드: 상태 점(파랑=실행 중, 주황=승인 대기, 초록=완료) + 세션명 + 경과 시간
- **승인 대기 세션은 목록에서 바로 처리**: 카드 안에 실행 예정 명령어 + [승인] [거부] 버튼 인라인 표시.
  카드를 클릭해 들어갈 필요 없음. 주황 테두리로 강조.
- 하단: [＋ 새 세션] 버튼

### ② 승인 알림 (푸시)
- 발신: 세션명 표시
- 내용: "이 명령을 실행할까요?" + 명령어 코드 표시
- 버튼: [승인](초록) / [거부]
- 알림 액션으로 앱 실행 없이 처리 가능해야 함

### ③ 결과 보기 (세션 상세)
- 상태 태그 + 3~4줄 요약 (빌드 성공, 배포 완료, 수정 파일 수, 테스트 통과 등)
- 하단 버튼: [🎤 지시] [전체 로그]

### ④ 음성 지시
- 큰 마이크 버튼 + 음성 파형 표시
- 인식된 텍스트 실시간 표시, 말을 마치면 자동 전송
- 전송 후 세션 상세로 복귀

### ⑤ 새 세션
- 프로젝트 선택 (드롭다운, /projects API)
- 첫 지시: 🎤 눌러서 음성 입력
- [세션 시작] 버튼 → POST /sessions
- 안내 문구: "핸드폰·데스크톱에도 자동으로 나타나요"

## 5. 개발 단계

- [ ] 워치 앱 뼈대: 세션 목록 화면 + API 연동

### 2단계 — 승인
- [x] 승인 프롬프트 감지 로직
- [ ] APNs 키 설정 + 푸시 발송
- [ ] 워치 알림 액션(승인/거부) + 목록 인라인 승인 버튼
- [x] approve/deny API → 클로드코드 세션에 결정 전달

### 3단계 — 지시와 결과
- [x] 결과 요약 생성 (브리지 서버에서)
- [ ] 세션 상세 화면 + 전체 로그 화면
- [ ] 음성 지시 화면 (받아쓰기 → /prompt)
- [ ] 새 세션 화면 (프로젝트 선택 + 음성 첫 지시)

### 4단계 — 마무리
- [ ] 공식 앱 세션 동기화 확인 (원격제어 모드 등록 검증)

## 6. 기술 스택 요약
- 브리지 서버: Node.js (Express) + `@anthropic-ai/claude-agent-sdk`
- watchOS 앱: SwiftUI, watchOS 10+
- 네트워크: Tailscale (사설망), APNs (푸시)
- 개발 환경: 맥북에어(macOS), Xcode 26, 애플 개발자 계정 보유 (TeamID __TEAM_ID__)

## 7. 주의사항
- 클로드코드 원격제어 기능은 연구 미리보기 단계라 세부 동작이 바뀔 수 있음
  → 세션 실행/등록 부분은 `sessions/drivers/` 모듈로 분리해 교체 쉽게 설계
- 워치 화면은 작으므로 모든 텍스트는 짧게, 승인 같은 핵심 동작은 탭 1번으로 끝나게
- 위험한 명령(삭제, 배포 등)은 승인 화면에서 명령어를 반드시 표시
- **다른 프로젝트(위드트립·위드택스·오네시스·테마레이더)에 영향 금지** — CLAUDE.md 참고

## 8. 세션 드라이버 두 가지

| | `sdk` (기본) | `remote-control` |
|---|---|---|
| 실행 방식 | Agent SDK `query()` | `claude --remote-control` (pty) |
| 승인 감지 | `canUseTool` 콜백 — **정확** | 화면 출력 파싱 — 취약 |
| 공식 앱 동기화 | ✗ | ✓ |
| 용도 | 워치에서 만든 세션 | 공식 앱과 같이 봐야 할 때 |

`BRIDGE_DRIVER` 환경변수로 전환합니다.
